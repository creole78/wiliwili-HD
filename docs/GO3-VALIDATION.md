# Go 3 定制版 v3 验收记录

日期：2026-09-26。目标：Windows 10/11 x64，GLFW / OpenGL。
当前测试电脑为 Windows 台式机，不是 Surface Go 3。使用独立测试配置，未使用原有账号登录信息。

## 已验证

- Release 编译成功；资源内嵌。自动测试通过：144 组旋转坐标往返，以及刷新阈值、回拉取消、重复释放、不可刷新和中断状态。
- 桌面主页、推荐数据、视频播放正常；旋转 90°、还原及旋转后的点击坐标已做界面检查。
- 原生输入框输入中文并提交，成功进入搜索结果页；v2 已移除 OSK 后备启动，仅使用原生触摸键盘。
- 视频最小化后进度从 64 秒持续到 96 秒；恢复后仍播放。手动暂停在 02:12，最小化等待约 45 秒再恢复，仍停在 02:12。
- F11 可切换无边框全屏。
- 快速鼠标下拉已实际触发一次推荐刷新，列表换成新内容，未误打开视频；日志记录 armed=true 和 refresh home recommends。
- 修复短时间批量鼠标事件丢失按下坐标的问题；Windows 触摸事件也保留开始、移动、结束顺序。
- 修复暂时没有 GLFW 显示器信息时的空指针崩溃。最终构建连续三次启动并初始化主页成功，三次都覆盖了桌面尺寸后备路径。
- 源码差异空白检查通过。

## 代码检查与待实机验证

最小化入口现为“屏幕＋向下箭头”，详情和全屏播放器控制栏新增“后台浏览”“最小化”；已检查详情页按钮与主页新图标的实际渲染。
本轮桌面输入测试工具出现 GetCursorPos 权限错误，因此后续用应用内部集成测试验证同一操作路径，不将其记作真实触摸点击验收。

v2 播放器集成测试使用真实 mpv 实例、网络视频和页面栈，已验证：暂停状态后台浏览并搜索后恢复不变；播放中退出全屏返回主页后进度继续；主页刷新和搜索不停止播放；恢复的是同一播放页面；详情页和全屏播放器分别最小化后播放均继续；选择新视频前旧播放器释放；清理后停止播放。测试退出码为 0。
这项测试由 `GO3_PLAYER_REGRESSION` 构建开关启用，发布包关闭该开关。

键盘代码检查确认：不再调用 ShellExecute 启动 OSK，也不再根据 1.2 秒后的 OccludedRect 值切换键盘。仅调用 InputPane.TryShow；TryHide 仅在关闭输入窗口时调用。

以下不宣称已经通过 Go 3 实机验收：重力传感器方向偏好、背折键盘触发、拼音候选字的全触摸操作、Windows 边缘手势和触控板切换应用、真实手指下拉及回拉手感。
原生输入框和系统键盘由 Windows 绘制，遵循系统方向；旋转按钮作用于应用渲染内容。
旋转按钮放在原版页脚；隐藏页脚的弹层不显示这些按钮，可关闭弹层后操作。

## 建议 Go 3 复核顺序

1. 解压完整运行包，在主页点消息按钮上方的屏幕箭头图标，确认回到桌面。
2. 播放视频后最小化，确认声音继续；手动暂停后最小化再恢复，确认仍暂停。
3. F11 全屏后用 Alt+Tab、边缘手势或触控板手势切换应用。
4. 打开“锁定应用方向”，转动设备；离开应用后检查系统仍按自己的设置旋转。
5. 点击旋转 90°和还原，检查按钮与视频点击位置。
6. 搜索框呼出系统键盘，切换到微软拼音，选择候选汉字并提交。
7. 推荐列表顶部下拉越过提示后松手刷新；再次下拉再回拉到阈值内松手，应不刷新。

## v3 回归结果（2026-09-26）

- 修复前新增“不透明且可见”断言，在原 v2 实现的恢复播放器步骤确定失败，退出码 1。
- 修复后同一流程通过，退出码 0。播放器根视图 alpha=1，不处于透明/隐藏状态。
- 在播放器下面放置绘制计数页面，分别验证暂停恢复、全屏退到后台后恢复：底层页面绘制次数均为 0。
- 测试故意设置为半透明的弹层，在保留、恢复之后仍保持半透明，避免破坏原版弹层。
- 模拟 OpenGL 遗留的裁剪和关闭写入状态，执行下一帧清屏后读取像素，确认清屏颜色正确。
- 暂停、后台浏览、搜索、刷新、详情/全屏最小化、恢复、换片和释放播放器的集成测试继续通过。
- 原生输入窗口调整为关闭前先启用主窗口，打开时先激活输入窗口；不再在销毁回调中强行抢回前台。原生触摸键盘路径保持 v2 的实现，不启动 OSK。

这些测试确认了透明叠加的原因及修复，并覆盖绘制状态；不能代替 Surface 对瞬时闪屏的肉眼验收。若设备上仍偶发闪屏，需要再按实际触发场景定位，不能据此保证不会出现任何卡死。

## v4 回归结果（2026-09-26）

代码审查发现并修复：窗口外触摸释放被过滤、触摸/鼠标积压事件跨页面回放、页面焦点引用在控件销毁后失效、无焦点页面未保存焦点栈位置、未排序释放队列使用二分查重，以及析构时向正在遍历的队列添加元素。

验证范围：

- 通过真实 GLFW 输入回调注入事件，经输入队列、Application 输入分发、手势识别、主页推荐网格到刷新回调，连续运行 30 轮。交替测试触摸和鼠标拖动、达到阈值松手及回拉取消：15 次刷新，15 次取消，没有额外刷新。
- 每轮包括主页按下未松开即最小化/恢复、恢复保留播放器后再次最小化/恢复和返回后台浏览；共 60 次最小化/恢复。每 3 轮加入全屏和连续两次后台浏览请求。
- 压力阶段保留真实主页布局、视频卡片和回收控件，用可计数的回调重载列表，使断言不依赖网络响应时间；此前独立步骤执行真实推荐网络刷新。
- 确认同一播放器恢复、不透明绘制、背景页不被绘制、播放继续、手动暂停不会恢复、新视频替换旧播放器和退出释放。
- 构造已销毁焦点的页面返回场景，以及重复、嵌套和锁定控件释放场景；验证所有控件各释放一次。
- 检查窗口大小变化后布局尺寸立即一致，保留 OpenGL 裁剪/写入掩码清屏像素测试。144 组旋转坐标往返及下拉阈值/取消/中断单元测试继续通过。

事件注入测试运行于 Windows 桌面，未模拟传感器或微软拼音键盘。窗口外松手与多指过滤另经代码检查；不能代替 Surface Go 3 真实触摸驱动和肉眼闪屏复测。v4 处理了绘制尺寸不同步的原因，但不宣称已在 Go 3 上确认所有瞬时闪屏消失。

## v5 退出及重启验收（2026-09-26）

使用同一个隔离配置目录，依次启动独立进程并从实际绑定的按钮/快捷键回调退出：主页电源按钮、主页 Ctrl+Shift+Q、详情播放器按钮、全屏播放器按钮、保留后台视频时的主页按钮、手动暂停后的播放器 Ctrl+Shift+Q，最后再次启动并播放视频后从详情页退出。

7 次进程均正常结束，退出码 0；每个播放场景都先等待真实 mpv 播放进度达到 3 秒。日志核验活动销毁、mpv 渲染上下文释放和 mpv 终止；同一配置目录可重新启动并播放，没有使用强制终止来冒充正常退出。这些检查验证入口绑定和退出生命周期，不代表真实触摸键盘或 Surface 传感器测试。
