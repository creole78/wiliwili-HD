# wiliwili Go 3 Windows 定制版 v8

## 使用

完整解压 `wiliwili-Go3-Windows-x64.zip`，在解压目录中运行 `wiliwili.exe`。
不要只复制 EXE：同目录的 DLL 是播放器和网络运行库，目标电脑无需安装 MSYS2。
适用于 Windows 10/11 x64；本版基于 1.6.0 源码和 GLFW/OpenGL 后端。

- 消息按钮上方依次是返回、最小化、关闭三个图标（Windows 风格的箭头、横线、叉号），
  返回只在后台有视频时出现，点它回到播放器；最小化调用原生窗口最小化，不发送 Esc。
- Windows 全屏使用不置顶的无边框窗口，取消键盘/手柄触发的鼠标锁定。
- 最小化和失焦不改变播放/暂停状态。后台继续处理 mpv 事件，隐藏时跳过界面绘制。
- 详情页和全屏播放页：轻点画面显示控制栏，右上角三个图标依次是返回、最小化、关闭。
  返回等于“后台浏览”，保留当前播放器并回主页，可继续搜索、刷新推荐；最小化直接回桌面。
- 后台浏览时，主页左侧出现返回图标，点它返回原播放器，保留进度和手动暂停状态。普通返回/关闭仍为退出播放；如要保留声音，请用返回键。打开另一视频会释放旧播放器。
- 边缘滑动返回（Android 风格）：手指从屏幕左边缘或右边缘向内滑动约 80 逻辑像素后松手即触发返回。
  播放器页返回等于“后台浏览”，主页返回会先弹出“是否关闭程序”的确认框。
  手势只在起点落在屏幕边缘 24 像素内时生效，从画面中间横向拖动仍然是拖动播放进度。
- 页脚“旋转 90°”“还原”旋转应用内容，并同步变换触摸/鼠标坐标；全屏播放保持所选方向。
- 设置 → 应用 → 窗口中新增“锁定应用方向”开关（默认开启并保存）。通过 Windows 进程级方向偏好固定启动方向，不修改系统旋转锁或注册表。
- Windows 搜索默认使用原生输入框，可使用系统拼音、候选字、剪贴板及物理键盘。
  打开时仅请求 Windows 原生触摸键盘，不再自动或手动启动 OSK 屏幕键盘。对话框内“触摸键盘”可再次请求。
  输入法需已在 Windows 安装；未自行捆绑拼音词库。输入窗口及系统键盘遵循 Windows 方向。
- 推荐列表顶部下拉约 144 个逻辑像素可松手刷新，回拉到阈值内取消；刷新有阻尼和回弹提示。
  鼠标按住左键拖动同样生效。加载期间不重复提交，保留原刷新按钮。
- 播放器支持网页端风格的键盘操作：← / → 快退快进 5 秒，↑ / ↓ 音量，M 静音，F 全屏，
  空格 播放/暂停，D 弹幕开关，数字键 0~9 跳转到对应进度。

默认继续使用原版配置位置 `%LOCALAPPDATA%\xfangfang\wiliwili`。
如需独立配置，可在启动进程环境变量 `WILIWILI_CONFIG_DIR` 指定另一目录。
当前旋转角度只在本次运行中保留，还原为启动时的应用方向。

## 构建

完整源码包含已补齐的依赖。MSYS2 UCRT64 需要 gcc、cmake、ninja、pkgconf、mpv、curl、libwebp。
在 PowerShell 执行：

```powershell
.\scripts\windows\build-go3.ps1 -MsysRoot C:\path\to\msys64 -Jobs 4
```

输出位于 `dist`；回归测试源码为 `tests/go3_interaction_test.cpp`。
原项目及依赖许可证继续适用，分发改版时应同时提供对应源码及修改。

## v2 更新方式

退出旧版 wiliwili，完整解压新包到新文件夹后运行，不要与旧版同时播放。应用配置仍沿用原位置。
本次修复 Surface 已经显示的原生触摸键盘被 OSK 替换的问题；已移除基于键盘遮挡区域的延迟后备判断。

开发者可使用 `-DGO3_PLAYER_REGRESSION=ON` 构建播放器集成测试，并在指定独立 `WILIWILI_CONFIG_DIR` 后运行。
测试会在线加载公开视频、执行暂停/后台浏览/搜索/刷新/恢复/最小化/换片/清理并自动退出。
发布构建必须恢复 `-DGO3_PLAYER_REGRESSION=OFF`；打包脚本会拒绝测试构建。

## v3 显示修复

- 修复从后台恢复播放器后与主页/搜索页透明叠加：退出动画的临时透明标记会在结束时恢复，播放器返回后独占页面绘制。
- 调整原生搜索窗口的打开/关闭顺序：先把焦点交给新窗口，关闭前先重新启用主窗口，减少焦点切走再切回造成的闪烁。
- Windows OpenGL 每帧清屏前恢复默认帧缓冲、裁剪和颜色/深度/模板写入状态，避免继承播放器或前一页面遗留的绘制状态。

前两版的后台浏览、最小化、原生触摸键盘和下拉刷新保留。

## v4 稳定性维护

- 页面切换、失焦和最小化时取消旧触摸/鼠标拖动并清空积压事件；窗口外松手也会结束触摸，第二根手指不会结束第一根手指的操作。
- 下拉刷新延迟到当前手势分发结束后执行，离开该页面或页面已销毁时不执行。
- 修复页面焦点保存中的失效指针、无焦点页面导致的栈错位，以及控件释放队列的重复入队和遍历失效。
- 全屏返回后台浏览期间合并重复操作，避免重复退出页面。
- 窗口尺寸与页面布局同步更新，避免恢复/调整尺寸时沿用旧尺寸绘制。

更新时请完全退出旧程序，将完整 v4 压缩包解压到新目录后启动。用户配置仍使用原目录，不需要重新登录。

## v5 停止并退出

主页左侧最小化图标下方新增电源图标；详情和全屏播放器的控制栏新增“退出程序”。主页和播放器均可按 Ctrl+Shift+Q 停止播放并退出。播放器控制栏隐藏时，先轻点画面即可看到按钮。

退出通过正常主循环执行：保存设置和播放进度、释放保留的后台播放器及活动页面，停止并销毁 mpv，释放本次播放的内存缓冲、解码和 GPU 资源，最后关闭窗口。销毁前取消播放器异步回调，防止回调继续引用已释放的资源。再次启动创建全新的播放实例，不沿用上一次的内存状态。登录、设置、历史记录保留；不删除用户媒体或正常的磁盘配置文件。

## v6 播放器键盘操作

详情页和全屏播放页新增一套与 B 站网页版一致的键盘操作，仅在播放器页面生效：

| 按键 | 功能 |
| --- | --- |
| ← / → | 后退 / 前进 5 秒 |
| ↑ / ↓ | 音量 ±5 |
| M | 静音 / 恢复静音前的音量 |
| F | 全屏 / 退出全屏（Esc 也可以退出全屏） |
| 空格 | 播放 / 暂停 |
| D | 弹幕开关 |
| 0~9 | 跳转到 0%~90% 进度 |

- 按方向键时焦点不再被移出播放器；焦点停在控制栏按钮上时，方向键仍用于在按钮之间切换。
- 数字键改为跳转进度后，音量快捷键由 0 / 9 改为 = / -；原有的 [ ] 快退快进、F1~F5、O 控制栏、
  P 长按加速等快捷键保持不变。
- 播放器设置里的 TV 控制模式保留原方向键逻辑，方便遥控器或手柄；触摸手势与鼠标操作不受影响。
- 网页端还有几个键在桌面端没有对应功能（W 网页全屏、P 画中画、回车发送弹幕），本版没有绑定。

## v7 闪屏修复

- 启动时窗口先以隐藏状态创建，等第一帧绘制完成后再显示，不再出现启动时黑屏一闪。
- 原生输入框（首页搜索框等）改为先在不可见状态下完成整窗绘制，再整体显示，
  不再出现点击搜索框时弹出黑屏。搜索仍使用 Windows 原生输入框与系统触摸键盘。

## v8 图标按钮与边缘返回

- 主页和播放器的“返回 / 最小化 / 关闭”不再使用自定义图标或文字，统一换成 Windows 风格的
  返回箭头、最小化横线和关闭叉号：主页左侧栏三个图标、播放器控制栏右上角三个图标。
  播放器控制栏由文字按钮改为图标按钮后更窄，标题的右侧留白同步收窄。
- 新增 Android 风格的边缘滑动返回：见上方“使用”一节。识别逻辑放在 `EdgeBackState`
  （`wiliwili/include/utils/edge_back.hpp`）里，与下拉刷新同样有单元测试覆盖。
- 播放器页的边缘手势注册在 OSD 手势之前，边缘滑动优先于进度拖动；画面中间的手势不受影响。
